# 🎌 Japanese Phonetic Name Generator

A Python application that translates English names into Japanese phonetic syllables. 

## 🚀 Features
* Continuous Loop:    Runs indefinitely until you type `quit`.
* Case-Insensitive:   Safely handles uppercase and lowercase inputs.
* Dictionary Mapping: Uses key-value data structures for translation.

### 🛠️ Built With
* Python 3 (Dictionaries, Loops, String Formatting)
* Git & GitHub
